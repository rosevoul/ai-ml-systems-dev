Project Overview

This project demonstrates an end‑to‑end recommendation system combining classical retrieval, modern transformer‑based ranking models and generative retrieval. Built on top of the MovieLens dataset, it illustrates how different architectures affect recommendation quality and user experience.

Included Models

  • Two‑Tower Retrieval + XGBoost: produces embeddings for users and items and applies a tree‑based ranker.
  • MBT4R / Transformers4Rec: leverages self‑attention to capture sequential viewing patterns.
  • LiGR: a set‑wise transformer that jointly scores slates of items using learned normalisation and attention.
  • Rank Transformer: a permutation‑invariant model optimised for listwise ranking.
  • Graph Transformer: attends over user–item graphs to incorporate multi‑hop relationships.

Future versions of this project will integrate retrieval‑augmented generation (RAG) and agentic workflows to generate natural language explanations and perform multi‑agent planning during recommendation.
